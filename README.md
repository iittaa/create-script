# 講座台本作成エージェントチーム

Claude Code のサブエージェント機能を使った、講座スライド動画の台本作成システムです。

## アーキテクチャ

```
あなた（ユーザー）
    │
    ▼
┌─────────────────────────────┐
│   メインエージェント（指揮者）  │  ← Claude Code メインセッション
│   全体の進行管理・最終確認     │
└──────────┬──────────────────┘
           │
           ▼
      ┌─────────┐
      │researcher│  ← リサーチ＋動画構成指示を生成
      └────┬────┘
           │
    ┌──────┼──────┐
    ▼      ▼      ▼
 ┌──────┐┌──────┐┌──────┐
 │writer││writer││writer│  ← 並列で台本執筆（3〜4本ずつ）
 └──────┘└──────┘└──────┘
           │
           ▼
    output/[コースタイトル]/
    [動画タイトル].md 〜（Googleドキュメントに変換してアップロード）
           │
           ▼
    Google Drive に自動アップロード
```

## プロジェクト構成

```
create-script/
├── CLAUDE.md                          # プロジェクト設定・規約
├── README.md                          # このファイル
├── upload_to_drive.py                 # Google Driveアップロードスクリプト
├── setup_drive_auth.py                # Google Drive初回認証スクリプト
├── .claude/
│   ├── agents/
│   │   ├── researcher.md              # リサーチエージェント（構成指示も担当）
│   │   └── writer.md                  # 台本執筆エージェント
│   └── commands/
│       └── create-script.md           # 台本作成ワークフロー
├── research/                          # リサーチレポート（中間成果物）
└── output/                            # 最終台本ファイル
```

## 使い方

### 前提条件

- Claude Code がインストール済みであること
- Anthropic API キーが設定済みであること

### 講座情報の設定（必須）

`CLAUDE.md` の「カスタマイズ設定」セクションにある以下の項目を、自分の講座に合わせて必ず編集してください。ここに書かれた内容が全エージェントの台本作成の前提になります。

- **講座名**: 何の講座か
- **対象ペルソナ**: 受講者像
- **台本スタイル**: `概要型`（講義）/ `ハンズオン型`（操作チュートリアル）/ `混合型`（前半講義＋後半操作）/ `臨機応変型`（内容に応じて自動判断）

### 初回セットアップ（Google Drive連携）

```bash
# 1. Google Drive APIの認証（初回のみ）
python3 setup_drive_auth.py
```

### 台本作成の実行

このプロジェクトディレクトリで Claude Code を起動し、以下を入力：

```
/create-script
```

以下の2つを伝えると自動で台本が生成されます（講座名はCLAUDE.mdから自動参照）：
- **コースタイトル**（例: メール対応の基礎）
- **動画タイトル一覧**（例: 10本分）

### 実行フロー

```
1. researcher がコース全体をリサーチ
   → research/[コースタイトル]/research_report.md に保存（動画構成指示含む）

2. writer が各動画の台本を並列執筆（3〜4本ずつ）
   → output/[コースタイトル]/[動画タイトル].md に保存

3. メインエージェントが品質チェック

4. Google Drive に自動アップロード（Googleドキュメントに変換）
   → python3 upload_to_drive.py output/[コースタイトル] --folder-name "[コースタイトル]"
```

## 各エージェントの役割

| エージェント | モデル | 役割 | 出力先 |
|------------|--------|------|--------|
| `researcher` | Sonnet | リサーチ＋動画構成指示の設計 | `research/` |
| `writer` | Opus | 台本（読み上げ原稿）執筆 | `output/` |

## 台本フォーマット

各動画の台本は以下のシンプルな形式で出力されます：

```markdown
# [動画タイトル]

[段落1]

[段落2]

...（話題の区切りごとに段落分け）

[最終段落（まとめ）]
```

- 本文は1900〜2100文字
- 話題の区切りごとに段落分け
- 前後の動画への言及なし・各動画単体で完結
- NotebookLM でスライドのノートとして利用することを想定しています。

## カスタマイズ

各エージェントの `.md` ファイルを編集することで調整できます：

- **トーン・文体**: `writer.md` の文体ガイドラインを変更
- **リサーチ深度**: `researcher.md` の調査項目を変更
- **文字数**: `writer.md` の文字数目安を変更
