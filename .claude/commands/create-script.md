# 台本作成ワークフロー

以下の手順で講座台本を作成してください。

## 入力情報の確認

ユーザーに以下を確認してください：
1. **講座名**: 何の講座か（例: オンライン秘書講座）
2. **コースタイトル**: コースの名前（例: メール対応の基礎）
3. **動画タイトル一覧**: 各動画のタイトル（例: 10本分）

## 実行手順

### Step 1: リサーチ
`researcher` エージェントを起動してください。

- 入力: ユーザーから受け取った講座名・コースタイトル・動画タイトル一覧
- 出力: `research/course_XX/research_report.md`（動画構成指示・動画間のつながりを含む）

### Step 2: 台本執筆（並列実行）
`writer` エージェントを動画3〜4本ずつのグループに分けて並列起動してください。

- 入力: `research/course_XX/research_report.md`
- 出力: `output/[コースタイトル]/[動画タイトル（指定通り）].md`（例: `1. 成果を出す人のマインドセット.md`）
- 各動画 1900〜2100文字の連続テキスト（スライド分割なし）

### Step 3: 最終確認
メインエージェントが以下を行います：
1. `output/[コースタイトル]/` の全ファイルを確認
2. 文字数・トーン・動画間のつながりをチェック
3. 問題があれば修正

### Step 4: Google Driveにアップロード
以下のコマンドを実行してください：

```bash
python3 upload_to_drive.py output/[コースタイトル] --folder-name "[コースタイトル]"
```

アップロード完了後、ユーザーに完了報告をしてください。

## 完了条件
- `output/[コースタイトル]/[動画タイトル].md` の形式で全動画の台本ファイルが揃っていること
- 全動画の本文が1900〜2100文字の範囲であること
- 動画間のつながりが自然であること
- Google Driveへのアップロードが完了していること
