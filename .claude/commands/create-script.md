# 台本作成ワークフロー

以下の手順で講座台本を作成してください。

## 入力情報の確認

ユーザーに以下を確認してください：
1. **コース番号**: 作成するコース番号（例: 01〜17）
   - `courses/course_XX.yaml` にコース定義が存在するか確認する
   - 存在しない場合はユーザーにコースタイトルと動画タイトル一覧を確認してYAMLファイルを作成する

## 実行手順

### Step 1: リサーチ
`researcher` エージェントを起動してください。

- 入力: `courses/course_XX.yaml` のコース定義
- 出力: `research/course_XX/research_report.md`（動画構成指示・動画間のつながりを含む）

### Step 2: 台本執筆（並列実行）
`writer` エージェントを動画3〜4本ずつのグループに分けて並列起動してください。

- 入力: `research/course_XX/research_report.md`
- 出力: `output/course_XX/video_01.md` 〜 `video_10.md`
- 各動画 1900〜2100文字の連続テキスト（スライド分割なし）

### Step 3: 最終確認
メインエージェントが以下を行います：
1. `output/course_XX/` の全ファイルを確認
2. 文字数・トーン・動画間のつながりをチェック
3. 問題があれば修正
4. ユーザーに完了報告

## 完了条件
- `output/course_XX/` に video_01.md〜video_10.md が揃っていること
- 全動画の本文が1900〜2100文字の範囲であること
- 動画間のつながりが自然であること
