# 台本作成ワークフロー

以下の手順で講座台本を作成してください。

## 入力情報の確認

ユーザーに以下を確認してください：
1. **講座テーマ**: 何についての講座か
2. **対象者**: 誰向けの講座か（初心者/中級者/上級者）
3. **講座の長さ**: 目安時間（10分/20分/30分など）
4. **特に伝えたいこと**: 必ず含めたいポイント（任意）

## 実行手順

### Step 1: リサーチ
`researcher` エージェントを使って、テーマに関する情報を収集してください。

プロンプト例：
```
researcher エージェントを使って、「[テーマ]」についてリサーチしてください。
対象者は[対象者レベル]です。
research/ ディレクトリにリサーチレポートを保存してください。
```

### Step 2: 構成設計
`architect` エージェントを使って、講座の構成を設計してください。

プロンプト例：
```
architect エージェントを使って、research/ のリサーチ結果をもとに
[X分]の講座構成を設計してください。
outline/ ディレクトリに構成案を保存してください。
```

### Step 3: 台本執筆
`writer` エージェントを使って、台本を執筆してください。

プロンプト例：
```
writer エージェントを使って、outline/ の構成案と research/ のリサーチ結果をもとに
台本を執筆してください。
output/ ディレクトリに最終ファイルを保存してください。
```

### Step 4: 最終確認・仕上げ
メインエージェント（あなた自身）が以下を行います：
1. output/ の台本ファイルを読み込む
2. 全体の整合性・品質をチェック
3. 必要に応じて修正
4. Google ドキュメントへのコピー用に最終Markdownを整形

## 完了条件
- `output/` に最終台本ファイルが保存されていること
- 全スライドの台本が CLAUDE.md のフォーマット規約に従っていること
- スライド間の流れが自然で論理的であること
